agent-blackbox

Claude Code, Codex CLI and Gemini CLI already write every session to your disk. agent-blackbox reads those logs and produces a turn-by-turn timeline, a risk audit based on 26 readable rules and an undo map. It sends nothing anywhere.

Every finding names the rule that fired, the session it fired in and the matched text, so you can disagree with one specific finding. The rules live in one file you can open, and any rule you disagree with can be switched off with --ignore.

Install

# once
> /plugin marketplace add halilneed/plugins

# the plugin
> /plugin install agent-blackbox@hailneed

# and try it
> /agent-blackbox:risk

The marketplace id is hailneed, which is why the install line ends in @hailneed.

  • Claude Code and Node.js 18 or newer.
  • No dependencies, no build step, no API key, no account.
  • It also runs standalone: node scripts/blackbox.mjs --scan --days 30 --md
  • For CI, --scan --out risk.json has a stable output format, so a build can fail when the risk score passes a threshold you set.

Commands

/agent-blackbox:timeline

The session turn by turn: what was asked, what ran, what broke and what changed. It also shows error chains, denied calls and where the time went.

/agent-blackbox:risk

An audit of what the agent was allowed to run: destructive commands, secrets that reached a transcript, permission and sandbox bypasses, and writes outside the workspace. Every high finding is verified against the transcript before it is reported. What cannot be verified is dropped.

/agent-blackbox:undo

Every file the agent touched, mapped to a recovery source (its own backup, git or a reverse patch), plus a separate list of what cannot be undone at all. It proposes a recovery and never restores anything on its own.

What it does and does not do

  • It makes no network calls. The scanner only reads files already on your disk, and blackbox.mjs contains no fetch and no sockets.
  • Secrets are masked before any report is written: API keys, JWTs, private-key headers and credentialed connection strings. Masking is on by default. --no-redact exists and is your call.
  • Thinking text never leaves the log. Only its count is reported.
  • There are 26 rules and no model judgement. rules.mjs is a pattern list you can read, and --selftest runs it against 33 fixtures without touching your data.
  • Unreadable sessions are counted in the source note.
  • MIT-licensed (LICENSE). No account, no signup, no telemetry.
