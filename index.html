01 Field kit

Three plugins for Claude Code.
One idea: show, do not tell.

Each one reads something that already exists on your machine — a session log, a public complaint thread, your own history — and returns a report that cites where every claim came from.

01

agent-blackbox

Flight recorder

Reads the session logs Claude Code, Codex CLI and Gemini CLI already write to your disk, normalises them into a single event schema and returns three things: a turn-by-turn timeline, a transparent risk audit of what the agent was allowed to run, and an undo map of what can still be reverted.

Every finding names the rule and the text it matched. The undo map proposes; it never restores on its own.

  • /agent-blackbox:timeline turn-by-turn flight record
  • /agent-blackbox:risk transparent risk audit
  • /agent-blackbox:undo recovery map, no auto-restore

02

painradar

Opportunity radar

Public complaints — Hacker News, GitHub Issues, App Store reviews and optionally Reddit — combined with verified-revenue proof from TrustMRR, turned into evidence-backed themes, a founder-opportunity fit ranking and a launch plan. Only public data is fetched.

A theme needs at least two linked sources before it makes the report. Unverified revenue is printed as unverified, never rounded up.

  • /painradar:scan 3–7 themes, cited, scored 1–5
  • /painradar:fit pain × money × gap × you
  • /painradar:launch one channel, 30-day calendar

03

devpersona

Developer profile

Reads your local Claude Code history and builds a character card — your stack, your working rhythm, your communication style, your risk patterns — with every claim cited to a transcript. Then turns that into skills worth writing, habits worth fixing and architecture advice.

The scanner puts no raw chat text in its default output. Raw prompt samples are opt-in and printed to the screen only.

  • /devpersona:analyze the character card

02 Install

Add the marketplace once.
Install any of them.

claude code 
# once
> /plugin marketplace add hailneed/plugins

# then whichever you want
> /plugin install agent-blackbox@hailneed
> /plugin install painradar@hailneed
> /plugin install devpersona@hailneed

# and try it
> /agent-blackbox:risk

Claude Code keys marketplaces by name, so a manifest shipped inside every product repo would overwrite the last one and the plugins could not coexist. A single manifest repository removes the clash — that is all hailneed/plugins is.

  • Claude Code and Node.js 18 or newer.
  • No dependencies, no build step, no API key.
  • Standalone works too — node scripts/blackbox.mjs --scan --days 30 --md
  • Optional — GITHUB_TOKEN, TRUSTMRR_API_KEY raise radar limits.

04 Method

Four rules the tools are built on.

01

Evidence over assertion.

A finding that cannot point at the line it came from does not ship. Reports cite the transcript, the rule and the matched text, so you can disagree with the specific thing rather than with the tool.

02

Local by default.

The data is already on your disk. Reading it should not require sending it anywhere. The blackbox scanner makes no network calls at all, and anything shaped like a credential is masked before a report is written.

03

Rules you can read.

Risk classification is a list of patterns in a file you can open, not a model judgement you have to trust. Disagree with one and switch it off with a flag.

04

Failure stays visible.

When a source is unreachable or a log will not parse, the report says so in its source note. Missing data never quietly becomes a confident number.
